## 샘플 데이터

2026-11-24, 별도 MySQL 8.4.13에서 `schema.sql` → `data.sql` → `verify_data.sql` 순서로 실행했다. 확장한 샘플 132행으로 테이블별 검사 11건(58개 컬럼)과 화면·데이터 관계 검사 13건이 모두 통과했다. 이미지 컬럼에 저장된 URL 8개가 저장소의 썸네일 파일 8개와 맞는지 확인했다. 우편번호와 품절 여부를 바꿨을 때 해당 검사가 실패하는 것도 확인했다.
